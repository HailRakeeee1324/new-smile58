# Архитектура сайта «Новая улыбка»

## Структура

- `src/App.jsx` — маршрутизация, ленивое подключение страниц и глобальные события.
- `src/pages/` — отдельные компоненты страниц.
- `src/components/` — переиспользуемые элементы интерфейса.
- `src/data/` — единый источник данных для врачей, услуг, цен, филиалов, акций, отзывов и статей.
- `src/config/` — маршруты и настройки сайта.
- `src/utils/` — аналитика и SEO.
- `src/styles/base.css` — переменные, типографика, контейнеры и базовые состояния.
- `src/styles/components.css` — шапка, меню, формы, футер и общие компоненты.
- `src/styles/home.css` — главная страница.
- `src/styles/pages.css` — внутренние страницы.
- `src/styles/responsive.css` — единая адаптивная система.

## Правила изменений

1. Не добавлять новые глобальные «hotfix»-блоки в конец CSS.
2. Исправлять исходное правило в профильном CSS-файле.
3. Контент врачей, услуг, цен и кейсов менять только в `src/data/`.
4. Для изображений задавать `width`, `height` или `aspect-ratio`.
5. Перед деплоем запускать `npm run check` и `npm run build`.
6. Новые страницы подключать через ленивый загрузчик в `src/App.jsx`.
