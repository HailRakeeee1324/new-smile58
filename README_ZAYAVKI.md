# Обработка заявок с формы записи

В сайт добавлена полноценная форма записи: имя, телефон и выбор района **Спутник / ГПЗ**.
Форма отправляет данные в серверный обработчик:

```text
/api/lead
```

Обработчик уже есть в архиве: `api/lead.js`.

## Как подключить получение заявок в Telegram

1. В Telegram откройте `@BotFather` и создайте бота командой `/newbot`.
2. Скопируйте токен бота.
3. Напишите любое сообщение созданному боту.
4. Узнайте `chat_id` через `@userinfobot` или через метод Telegram `getUpdates`.
5. В Vercel откройте проект сайта → **Settings → Environment Variables**.
6. Добавьте переменные:

```text
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id_или_id_группы
```

7. Перезапустите деплой.

После этого заявки будут приходить в Telegram в таком составе:

- имя пациента;
- телефон;
- выбранный район: Спутник или ГПЗ;
- страница, с которой отправили заявку;
- UTM-метки, если пользователь пришёл из рекламы.

## Альтернатива: отправка в CRM / webhook

Если позже будет CRM, можно добавить переменную:

```text
LEADS_WEBHOOK_URL=https://адрес_вашего_webhook
```

Тогда заявка будет отправляться ещё и туда JSON-запросом.

## Важно

Без `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` или `LEADS_WEBHOOK_URL` сайт не может физически отправить заявку администратору, потому что у браузера нет безопасного адреса доставки. В таком случае форма сохранит тестовую заявку в браузере, но для боевого сайта нужно указать переменные окружения на Vercel.
