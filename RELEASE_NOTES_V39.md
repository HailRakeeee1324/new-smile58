# Release Notes V39 — исправление production build

Исправлена ошибка SEO-аудита, из-за которой favicon, apple-touch-icon и site.webmanifest с query-параметром `?v=4` ошибочно считались ссылками на отсутствующие HTML-страницы.

Изменения:

- внутренние ссылки проверяются только в тегах `<a href>`;
- статические ресурсы с query/hash корректно исключаются из проверки;
- добавлена проверка синтаксиса `scripts/seo-audit.mjs` в `npm run check`;
- визуальная часть сайта и SEO-контент не менялись.
