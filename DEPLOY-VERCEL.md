# Деплой проекта на Vercel

Ниже инструкция в том же практическом формате — без лишней воды.

## 1) Что уже готово в проекте
- фронтенд на **Vite + React**
- серверная функция для заявок: **`/api/lead.js`**
- конфиг Vercel уже есть: **`vercel.json`**
- сайт рассчитан на деплой как единый проект на Vercel

---

## 2) Что загрузить на Vercel
Загружай **весь проект целиком** из этой папки, а не только `dist`.

То есть в Vercel нужен исходный проект со структурой примерно:
- `src/`
- `public/`
- `api/`
- `package.json`
- `vite.config.js`
- `vercel.json`

---

## 3) Как задеплоить
### Вариант A — через сайт Vercel
1. Зайди в **Vercel**
2. Нажми **Add New Project**
3. Импортируй проект из GitHub
4. Framework Vercel обычно определит сам как **Vite**
5. Проверь настройки:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
6. Добавь переменные окружения (ниже)
7. Нажми **Deploy**

### Вариант B — через CLI
```bash
npm i -g vercel
vercel
```
Дальше:
- выбрать текущую папку проекта
- подтвердить настройки
- добавить env-переменные
- затем продакшн-деплой:
```bash
vercel --prod
```

---

## 4) Переменные окружения в Vercel
Добавь в **Project Settings → Environment Variables**:

### Обязательные
```env
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=id_чата_или_группы
YANDEX_SMARTCAPTCHA_SERVER_KEY=серверный_ключ_капчи
VITE_YANDEX_SMARTCAPTCHA_CLIENT_KEY=клиентский_ключ_капчи
```

### Что они делают
- `TELEGRAM_BOT_TOKEN` — бот, через которого приходят заявки
- `TELEGRAM_CHAT_ID` — чат/группа, куда падают заявки
- `YANDEX_SMARTCAPTCHA_SERVER_KEY` — проверка капчи на сервере
- `VITE_YANDEX_SMARTCAPTCHA_CLIENT_KEY` — публичный ключ для фронта

---

## 5) После деплоя обязательно проверить
### Фронт
- главная страница открывается
- открываются страницы услуг
- открываются статьи блога
- нормально работает мобильная версия
- карусели двигаются плавно

### Формы
Проверить кнопку **«Записаться»** и отправку заявки:
1. открыть модалку
2. заполнить имя/телефон
3. выбрать район
4. пройти капчу
5. отправить
6. убедиться, что заявка пришла в Telegram

---

## 6) Если заявки не приходят
Проверь по порядку:
1. правильно ли заполнены env-переменные
2. добавлен ли бот в нужный чат
3. есть ли у бота право писать в чат
4. не пустой ли `TELEGRAM_CHAT_ID`
5. корректны ли ключи SmartCaptcha
6. смотри **Vercel → Functions → Logs**

---

## 7) Если после деплоя не открываются внутренние страницы
В этом проекте уже лежит `vercel.json`, поэтому роутинг и редиректы должны работать нормально.
Если меняешь домен — просто redeploy.

---

## 8) Локальный запуск перед деплоем
```bash
npm install
npm run dev
```
Для локальной production-проверки:
```bash
npm run build
npm run preview
```

---

## 9) Рекомендуемый порядок действий
1. Залить проект в GitHub
2. Подключить репозиторий к Vercel
3. Прописать env-переменные
4. Сделать deploy
5. Проверить форму заявок
6. Проверить мобильную версию
7. Подключить домен `new-smile58.ru`
8. После привязки домена сделать повторную финальную проверку
