# Release Notes V40 — старт без SEO-flash + подтверждение записи

Исправлено два пользовательских сценария:

1. При первом открытии страницы больше не показывается на долю секунды сырой prerender/SEO-текст до загрузки React-интерфейса. Добавлен минимальный boot-shield, который закрывает только короткий период до первого React-render и автоматически снимается через `useLayoutEffect`. При отключённом JavaScript SEO-fallback остаётся доступным через `noscript`.

2. После успешной отправки формы запись теперь подтверждается отдельным заметным состоянием внутри модального окна:
   - заголовок «Заявка принята»;
   - текст: «Заявка принята. Администратор «Новой улыбки» позвонит вам в ближайшее время, чтобы уточнить детали и подобрать удобное время приёма.»;
   - кнопка «Хорошо» закрывает окно;
   - оставлена быстрая кнопка звонка в клинику.

Функция отправки заявки, SmartCaptcha, Telegram/Vercel API и SEO-prerender не удалялись и продолжают работать по прежней схеме.
