Novaya Ulybka — mobile polish v22

Что изменено:
1. По умолчанию сайт теперь стартует со светлой темы.
2. Улучшен блок преимуществ на главной: глубже визуал, завершённые карточки, лучше тёмная/светлая тема.
3. Мобильный блок «Основные направления» переведён в компактный горизонтальный слайдер-карусель.
4. На мобилке порядок блока изменён: Руководитель -> О клинике -> Пространство клиники.
5. Подвал переработан по отступам, выравниванию и адаптивности.
6. Отзывы стабилизированы по высоте, кнопки не дёргают страницу, на мобилке поддержан свайп.
7. Страница «До/После» получила более выразительные карточки историй.
8. Окно записи и окно капчи рендерятся через portal и центрируются по экрану.

Основные изменённые файлы:
- src/App.jsx
- src/pages/HomePage.jsx
- src/pages/ReviewsPage.jsx
- src/components/AppointmentModal.jsx
- src/styles/final-polish-v22.css

Команды локально:
1. npm install
2. npm run build
3. npm run preview

Если деплой в Vercel:
1. Залить обновлённый проект в Git
2. В Vercel нажать Redeploy
3. Убедиться, что переменные окружения формы и капчи сохранены
