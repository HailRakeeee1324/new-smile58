# Релиз v16 — архитектура, прайс, кейсы и мобильная навигация

## Прайс

- Поиск по названию услуги и направлению.
- Быстрые фильтры: консультации, гигиена, лечение, протезирование, хирургия, имплантация и эстетика.
- Фильтрация выполняется на уровне каждой позиции, а не только целой категории.
- У каждой позиции есть ссылка на связанную страницу услуги.
- У каждой позиции есть отдельное пояснение о составе стоимости и возможных дополнительных этапах.
- Сохранено предупреждение о том, что окончательный план и стоимость определяются после диагностики.

## До / После

- Кейсы оформлены как клинические истории.
- Для каждого случая указаны причина обращения, проблема, выполненное лечение, этапность и результат.
- Добавлены ссылки на соответствующие услуги.
- Добавлены индивидуальные предупреждения и общий медицинский дисклеймер.

## Мобильная навигация

- Нижняя панель содержит только три действия: «Позвонить», «Записаться», «Филиалы».
- Для контента зарезервировано место, поэтому панель не закрывает нижнюю часть страницы.
- Панель скрывается при открытии формы записи и мобильного меню.
- В компактном меню выделены быстрые разделы: цены, врачи, акции и услуги.

## Архитектура

- Монолитный `main.jsx` разделён на `App`, страницы, компоненты, конфигурацию, данные и утилиты.
- Врачи, услуги, цены, филиалы, акции, отзывы и статьи вынесены в `src/data`.
- Стили разделены на базовые, компонентные, главную, внутренние страницы и адаптив.
- Удалён старый `src/styles.css` и устаревшие патчи V6–V15.
- SEO-пререндер использует те же данные прайса и клинических историй, что и React-интерфейс.
- Добавлен `ARCHITECTURE.md` с правилами дальнейшей разработки.

## Производительность и стабильность

- Внутренние страницы и форма записи подключаются через `React.lazy`.
- Код раздела подгружается при переходе; наведение и фокус заранее прогревают нужный чанк.
- Мобильные версии крупных изображений подключены через `srcset`.
- У изображений фиксируются размеры и пропорции, чтобы уменьшить скачки макета.
- Метрика откладывается до первого взаимодействия или завершения загрузки первого экрана.
- SmartCaptcha загружается только при фактической отправке формы.
- Удалены неиспользуемые CSS-правила и дубли старого прайса; исходный CSS уменьшен примерно на 32 КБ.
- Горизонтальные reveal-анимации заменены на спокойное вертикальное появление.
- Добавлена команда `npm run check` для проверки структуры, импортов, ресурсов и обязательных данных.
