# Mobile final QA patch

Внесены финальные правки по мобильной версии сайта:

1. Убрана мобильная подсказка о переключении светлой/тёмной темы.
2. Исправлена мобильная шапка и навигация: убраны лишние полосы, улучшен active-state, активный пункт меню автоматически докручивается в видимую область.
3. Доработана главная страница:
   - усилена и возвращена фоновая надпись «НОВАЯ УЛЫБКА»;
   - выровнены цвета и фоновые слои;
   - карточки адресов в светлой теме сделаны голубыми.
4. Исправлены стрелки в блоке спецпредложений — теперь они центрируются по вертикали.
5. Исправлена мобильная hero-зона внутренних страниц в светлой и тёмной темах.
6. Исправлено окно записи:
   - фиксированное открытие по центру;
   - без вертикального скролла внутри модального окна;
   - кнопки районов «Спутник» / «ГПЗ» выровнены и стилизованы одинаково.
7. На странице «Акции» исправлено перечёркивание старой цены — красная линия проходит только по цене.
8. Исправлено отображение баннера ПроДокторов внизу — убран чёрный фон, добавлена белая/аккуратная подложка.
9. Архив оптимизирован: для финальной версии исключены `node_modules` и `dist`, чтобы уменьшить размер.

## Что загружать

Используйте архив `novaya_ulybka_mobile_final_qa_source.zip`.

## После распаковки

```bash
npm install
npm run build
```

Далее можно коммитить и пушить в GitHub / Vercel.
