## Robots и Sitemap

`robots.txt`:

- разрешает обход основных страниц;
- не блокирует CSS, JavaScript и изображения;
- содержит ссылку на sitemap;
- содержит `Clean-param` для UTM, `yclid`, `ymclid` и `erid`.

`sitemap.xml`:

- содержит только канонические страницы;
- не содержит рекламных параметров;
- не содержит страниц 404, редиректов и дублей;
- содержит 39 индексируемых canonical URL.

## Дубли и редиректы

В `vercel.json` добавлены постоянные редиректы:

- `/stomatologiya-penza` → `/`
- `/stomatologiya-v-penze` → `/`
- `/luchshaya-stomatologiya-penza` → `/`

Формат URL сохраняется без завершающего слеша, canonical формируется по чистому URL без рекламных параметров.

- синтаксическая проверка prerender, Vite config и API;
- автоматический SEO-аудит;

Полная Vite-сборка в контейнере не выполнялась из-за недоступности внешнего npm-реестра. Команда `npm run build` должна быть выполнена локально перед деплоем; после Vite и prerender она автоматически запускает SEO-аудит.
