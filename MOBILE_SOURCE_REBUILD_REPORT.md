# Финальная мобильная версия из исходного архива

В этот архив внесены финальные правки мобильной версии на базе исходного архива пользователя:
- исправлена мобильная шапка и главный экран;
- убрано мобильное уведомление о смене темы;
- форма записи сделана компактной, фиксированной и без лишнего внутреннего скольжения;
- кнопки Спутник / ГПЗ в форме записи выровнены и нормализованы;
- нижняя мобильная панель Позвонить / Записаться / Адреса выровнена;
- добавлены жёсткие мобильные CSS-правила поверх старых стилей;
- удалены тяжёлые PNG-дубликаты, оставлены WebP;
- проект проверен через npm run build и prerender.
