# V49 — раскрывающиеся карточки услуг

- Карточки на странице «Услуги» по умолчанию показывают только фотографию, название и явный индикатор раскрытия.
- Вся верхняя часть карточки является кликабельной через нативный `<details>/<summary>`.
- После раскрытия появляются описание, показания, этапы, ориентиры по стоимости и кнопки действий.
- Стрелка плавно поворачивается, подпись «Подробнее» меняется на «Свернуть».
- Добавлена отдельная адаптация для мобильных экранов и тёмной темы.
- SEO-текст остаётся в HTML и доступен поисковым роботам даже при визуально свернутой карточке.
