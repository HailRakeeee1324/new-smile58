# SEO и скорость — что сделано в этой версии

## SEO под Яндекс

Сайт уже был неплохо подготовлен: есть ЧПУ-адреса, отдельные страницы услуг, блог, sitemap, robots, мета-теги, микроразметка и Яндекс Метрика.

В этой версии усилены слабые места:

1. Добавлены дополнительные локальные SEO-посадочные страницы:
   - `/stomatologiya-sputnik` — стоматология в Спутнике;
   - `/stomatologiya-gpz` — стоматология на ГПЗ;
   - `/semeynaya-stomatologiya-penza` — семейная стоматология в Пензе;
   - `/implantaciya-zubov-penza` — коммерческая посадочная под имплантацию зубов в Пензе.

2. В раздел «Услуги» добавлен блок внутренних SEO-ссылок: услуги + районные посадочные страницы.

3. `sitemap.xml` теперь генерируется автоматически при сборке и включает 39 страниц.

4. `robots.txt` теперь тоже генерируется при сборке, закрывает технические параметры и указывает актуальный sitemap.

5. Canonical, Open Graph, description и JSON-LD продолжают проставляться на статически сгенерированных страницах.

> Важно: если финальный домен будет не `https://novaya-ulybka.ru`, нужно заменить переменную `PUBLIC_SITE_URL` в Vercel и/или в `.env.example`.

## Скорость

1. Оптимизированы изображения:
   - уменьшены размеры тяжёлых фото врачей, филиалов, услуг, отзывов, до/после и промо-баннера;
   - сохранён WebP-формат;
   - суммарно в `public` уменьшено примерно на 1.6+ МБ.

2. Для статики добавлены cache headers в `vercel.json`:
   - `/assets/*`;
   - JS/CSS;
   - изображения.

3. Яндекс Метрика загружается не сразу, а после загрузки страницы/idle-периода, чтобы меньше мешать первому экрану.

4. Добавлены preconnect/dns-prefetch для внешних ресурсов.

5. В index fallback добавлены ссылки на ключевые страницы, чтобы даже без JS структура оставалась понятной для поисковика.

## Что проверить после деплоя

1. Открыть `/sitemap.xml` и убедиться, что домен правильный.
2. Открыть `/robots.txt` и убедиться, что sitemap ведёт на правильный домен.
3. Добавить сайт в Яндекс Вебмастер.
4. Отправить sitemap на переобход.
5. Проверить цели в Яндекс Метрике.
