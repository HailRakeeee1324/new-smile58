1. Распакуйте архив в отдельную папку.
2. Если хотите обновить текущий проект, замените файлы в вашей рабочей папке этим содержимым.
3. Откройте терминал в папке проекта.
4. Выполните: npm install
5. Для локальной проверки: npm run dev
6. Для отправки на сайт: git add . && git commit -m "Update inner page headers and premium backgrounds" && git push origin main
7. Vercel сам соберёт и задеплоит сайт. После деплоя обновите страницу через Ctrl+F5.

Изменения в этом архиве:
- новые шапки внутренних страниц для светлой и тёмной тем;
- переработанный фон сайта с глубиной, подсветками и glass/premium эффектом;
- обновлён styles.css;
- добавлены файлы public/page-hero-inner-light.webp и public/page-hero-inner-dark.webp.
