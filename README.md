# Новая улыбка — сайт стоматологии

## Важно

В архиве специально нет `node_modules`.
`package-lock.json` оставлен, чтобы зависимости ставились предсказуемо и без сюрпризов.

## Запуск проекта

1. Распакуй архив в новую чистую папку, например:

```text
C:\Users\HailRake\novaya-ulybka-fixed
```

2. Открой эту папку в VS Code.

3. В терминале выполни:

```bash
npm install
npm run dev
```

4. Открой ссылку:

```text
http://127.0.0.1:5173/
```

## Если снова будет ошибка EPERM

Закрой запущенный сервер через `Ctrl + C`, закрой браузерную вкладку сайта и выполни в PowerShell из папки проекта:

```powershell
Remove-Item -Recurse -Force node_modules
Remove-Item -Force package-lock.json
npm install
npm run dev
```

## Оптимизация изображений

Основные изображения проекта переведены в WebP. Для крупных фоновых изображений дополнительно созданы AVIF-версии и подключены через `image-set()` с WebP-fallback. Оригинальные тяжёлые PNG/JPG удалены из проекта, чтобы уменьшить размер деплоя.

## Заявки с формы записи

Форма записи теперь отправляет имя, телефон и выбранный район (**Спутник / ГПЗ**) в обработчик `/api/lead`.
Для боевого получения заявок добавьте в Vercel переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Подробная инструкция — в файле `README_ZAYAVKI.md`.

## Яндекс Метрика

Счётчик подключён через переменную окружения:

```bash
VITE_YANDEX_METRIKA_ID=109447302
```

Локально можно создать файл `.env` по примеру `.env.example` и вставить реальный ID счётчика.
На Vercel добавьте эту же переменную в Project Settings → Environment Variables.

В коде уже настроены JavaScript-цели:

- `click_phone` — клик по номеру телефона;
- `click_whatsapp` — клик по WhatsApp;
- `click_telegram` — клик по Telegram, когда будет добавлена ссылка на Telegram;
- `click_messenger` — общий клик по мессенджеру;
- `click_appointment_button` — клик по кнопке записи;
- `appointment_modal_open` — открытие окна записи;
- `appointment_form_submit` — отправка формы записи;
- `open_contacts_page` — переход на страницу контактов;
- `click_address_map` — клик по адресу / карте;
- `click_prodoctorov` — переход на ПроДокторов.

В Метрике для них нужно создать цели типа «JavaScript-событие» с такими же идентификаторами.
