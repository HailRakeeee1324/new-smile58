# Новая улыбка — Conversion Home v25

Полностью заменена структура главной страницы на конверсионную последовательность из шести блоков:

1. Обложка клиники с фотографиями трёх филиалов в адресных карточках.
2. Интерактивная карусель «Что вас беспокоит?» с центрированием выбранной жалобы.
3. Блок популярных услуг и реальных цен с переходами на страницы услуг.
4. Карусель врачей с увеличенной выбранной карточкой.
5. До/После с реальными фотографиями, краткой историей лечения и CTA.
6. Карусель семи реальных отзывов и три ссылки на отзывы филиалов в Яндекс Картах.

Технические особенности:

- отдельный канонический CSS главной страницы без наследования старой home-вёрстки;
- адаптив для desktop, tablet и mobile;
- свайпы и стрелки в каруселях;
- центрирование выбранных карточек;
- фиксированные размеры медиа и карточек для уменьшения скачков страницы;
- светлая и тёмная темы;
- существующие внутренние страницы, форма записи, аналитика и SEO-маршруты сохранены.
