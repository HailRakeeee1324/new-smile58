# V53 — временно отключена SmartCaptcha

- Полностью удалена клиентская Yandex SmartCaptcha из формы записи.
- Удалена серверная проверка SmartCaptcha в `/api/lead`.
- После заполнения имени, телефона, района и согласия заявка отправляется сразу в Telegram.
- Добавлена защита от двойного клика/повторной отправки во время запроса.
- Добавлено невидимое honeypot-поле для отсечения простых спам-ботов без участия пациента.
- Переменные `VITE_YANDEX_SMARTCAPTCHA_CLIENT_KEY` и `YANDEX_SMARTCAPTCHA_SERVER_KEY` в Vercel больше не используются этой версией сайта.
