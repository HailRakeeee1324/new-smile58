# Настройка Яндекс Метрики для сайта «Новая улыбка»

## 1. Создать счётчик

В Яндекс Метрике создайте счётчик для домена сайта. В настройках счётчика включите:

- Вебвизор;
- карта кликов;
- карта скроллинга;
- аналитика форм, если доступна в интерфейсе;
- отслеживание переходов по внешним ссылкам.

## 2. ID счётчика уже встроен в код

В проекте счётчик Яндекс Метрики подключён напрямую в `src/main.jsx`.

Текущий ID счётчика:

```text
109447302
```

Переменные окружения Vercel для Метрики сейчас не нужны. После деплоя сайта статистика будет поступать в счётчик `109447302`.

Проверка на сайте:

1. Откройте сайт.
2. Нажмите `F12`.
3. Вкладка `Network`.
4. В поиске введите `mc.yandex`.
5. Должен появиться запрос к `mc.yandex.ru/metrika/tag.js?id=109447302`.

## 3. Создать цели в Метрике

В Яндекс Метрике создайте цели типа «JavaScript-событие» со следующими идентификаторами:

| Цель | Идентификатор |
|---|---|
| Клик по номеру телефона | `click_phone` |
| Клик по WhatsApp | `click_whatsapp` |
| Клик по Telegram | `click_telegram` |
| Клик по мессенджеру | `click_messenger` |
| Клик по кнопке записи | `click_appointment_button` |
| Открытие окна записи | `appointment_modal_open` |
| Отправка формы записи | `appointment_form_submit` |
| Переход на страницу контактов | `open_contacts_page` |
| Клик по адресу / карте | `click_address_map` |
| Переход на ПроДокторов | `click_prodoctorov` |

## 4. UTM-метки для рекламы

Для рекламы используйте ссылки такого вида:

```text
https://site.ru/uslugi/implantaciya?utm_source=yandex&utm_medium=cpc&utm_campaign=implantaciya_penza&utm_content=search_ad_1&utm_term={keyword}
```

Сайт сохраняет UTM-метки в `localStorage` и передаёт их вместе с целями Метрики.

## 5. Важно про форму

На сайте добавлена клиентская форма в модальном окне записи. Сейчас она фиксирует событие отправки формы в Метрике. Для реальной передачи заявок администратору нужно подключить отдельный backend / CRM / почтовый сервис.
