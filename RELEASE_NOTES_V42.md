# V42 — blur + dark header + default light theme

## Исправлено

1. Убран постоянный blur на мобильных страницах.
   Причина была в старом `filter: blur(10px)` на `.reveal-on-scroll`: V41 отключала анимацию на мобильных, но лениво загруженные разделы могли смонтироваться уже после первичной установки `is-visible`.
   V42 принудительно сбрасывает `filter` для reveal-элементов на мобильных и touch-устройствах.

2. Убран потенциальный iOS Safari backdrop-layer от закрытого мобильного меню.
   Закрытое меню теперь полностью `display: none`, поэтому оно физически не может размывать страницу под собой.

3. Убраны blur-снимки View Transition API.
   Внутренняя навигация теперь переключается сразу, а тема меняется обычным лёгким CSS-переходом без снимка всей страницы.

4. На тёмной теме главная шапка теперь без прямоугольной рамки/подложки.
   Добавлен высокоспецифичный финальный override, который не может быть перебит лениво загруженным `pages.css`.

5. Каждый новый вход/перезагрузка сайта начинается со светлой темы.
   Тёмную тему по-прежнему можно включить кнопкой, но она не сохраняется между перезагрузками.
